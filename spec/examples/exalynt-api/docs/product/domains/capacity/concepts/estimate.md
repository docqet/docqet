An estimate is an ordered list of focuses, each sized S, M, L, or XL
and planned at a pace, with an optional description and ordered notes. A focus is
whatever the work is grouped by: a new feature, or an improvement or enhancement
to an existing system.

Sizes span ranges of [capacity units](capacity-unit.md), which add up to the
estimate's totals. A focus's pace is the [block](capacity-block.md) type (Flex,
Core, or Dedicated) bought and used once a week for it, which sets its price per
unit and how many weeks its size takes. A focus written without one is planned at
Dedicated. Every focus, and the project, is still shown on every block, so the
client sees what each would cost and take.

An estimate can also carry discounts, each a whole-number percentage off the
whole project. It belongs to an [organization](../../accounts/concepts/organization.md), or to none, such
as a prospect's before they sign up.
