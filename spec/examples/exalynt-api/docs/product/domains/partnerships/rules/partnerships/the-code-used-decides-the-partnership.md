name: The code used decides the partnership
---

An invited address is attributed by the code it uses, even if another partner
invited it. With no code, it's attributed to the partner who invited it, when
just one has, and otherwise to nobody. Either way, it came by invitation when
the partnership it's attributed to invited that address, as the invitation's
link carries the code.
