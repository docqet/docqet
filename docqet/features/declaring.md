---
docqet: feature
id: declaring
name: Declaring intention
description: >-
  Writing what the software is meant to do as docs beside its code, and
  linking the evidence of what it does to them.
area: area:authoring
tradeoffs:
  - id: docs-written-by-hand
    name: Docs written by hand
    description: >-
      There's no command that writes a doc, such as `docqet new capability`.
      Agents write docs from the kit, and people copy one.
    benefit: >-
      Nothing to build, or to keep in step with the format, while the format is
      still changing.
    drawback: >-
      Writing a doc means knowing its fields, or finding one to copy. Revisit
      if writing docs by hand turns out to be slow.
---
