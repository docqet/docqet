---
docqet: rule
id: nothing-only-an-agent-can-do
name: Nothing only an agent can do
why: >-
  Docs that only an agent can keep current stop being kept the day the agent
  isn't there, and people stop trusting what they can't check or change
  themselves.
---

Everything an agent does with Docqet goes through files a person can read
and edit, and commands a person can run. The kit tells agents how to use
them; it gives them nothing a person doesn't have.
