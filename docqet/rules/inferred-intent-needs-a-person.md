---
docqet: rule
id: inferred-intent-needs-a-person
name: Intention an agent works out counts only once a person confirms it
why: >-
  Intention read from code repeats the code's bugs, and what the software is
  meant to do is people's to decide. An agent can propose it; only a person
  can make it so.
---

An agent proposes intention it infers, from the code, tests or old docs, and
writes it down only once a person has stated or confirmed it. Until then it's
a question, recorded as an open decision or asked outright.
