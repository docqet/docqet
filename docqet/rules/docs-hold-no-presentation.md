---
docqet: rule
id: docs-hold-no-presentation
name: Docs hold facts, not how to show them
why: >-
  How something is shown depends on who's looking and why, and changes with
  every view. A doc that set an order or a layout would be edited for reasons
  that have nothing to do with the software.
---

Nothing in a doc sets the order things are shown in, how they're grouped on
a page, or how they look. Readers sort and group however each view needs:
by level, readiness, problem or name.
