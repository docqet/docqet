name: An Engineer Agreement can have no Commercial Terms
---

An admin can send an Engineer Agreement with no Commercial Terms, whether with
an invitation or later. The engineer then earns nothing (see [Unlisted shares
earn nothing](../earnings-and-payouts/unlisted-shares-earn-nothing.md)), and the admin confirms
that before sending.
