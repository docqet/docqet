name: Shared queue
description: >-
  Each client's scheduled, unassigned blocks. Engineers and leads on any team
  assigned to that client can see it, and no team owns it.
---

Each client [organization](organization.md) has one shared queue, made up of its
[capacity blocks](capacity-block.md) that have a
[preferred week](preferred-week.md) and no engineer yet. The
[teams](team.md) assigned to the client see the same queue.
