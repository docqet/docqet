name: Fulfilled
description: >-
  A block is fulfilled once its engineer marks it fulfilled. Nobody reviews
  it, and marking it fulfilled is final.
confused-with:
  - concept: concept:payout
    summary: >-
      a separate lifecycle that starts once a block is fulfilled. A
      fulfilled block isn't necessarily paid out.
---

Fulfilled describes a [capacity block](capacity-block.md) that has reached
Fulfilled in its lifecycle. It keeps when it was fulfilled. A block fulfilled
before review was removed keeps its approval's time.
